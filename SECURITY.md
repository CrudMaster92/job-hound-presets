# Security

Presets are data, but they can direct network requests. Treat every contribution as untrusted until it passes automated validation and human review.

Do not report security vulnerabilities in a public issue. Contact the repository owner privately through their GitHub profile. Never commit secrets, access tokens, cookies, authorization headers, private careers endpoints, or personal job-search data. If a secret is committed, revoke it immediately; deleting the file does not remove it from Git history.
